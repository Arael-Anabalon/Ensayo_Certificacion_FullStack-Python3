## Descripción
Donación de Peluches es una aplicación web para la gestión, registro y adopción de juguetes de felpa desarrollada bajo el patrón arquitectónico MVC (Modelo-Vista-Controlador). El sistema incluye autenticación modular de usuarios con encriptación Bcrypt mediante Blueprints, validación rigurosa de formularios con persistencia de datos (previos), operaciones CRUD completas con borrado lógico, un sistema interactivo de adopciones y un contador matemático incremental de visualizaciones por registro en la base de datos.
